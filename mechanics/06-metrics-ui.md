# 06. Метрики и показатели для UI

Все показатели считает воркер симуляции и отправляет в главный поток пакетом `MetricsSnapshot` раз в игровой час (быстрые) и раз в день/месяц (тяжёлые). История для графиков — кольцевой буфер: 48 точек по часам, 120 по дням, 120 по месяцам (≈ 10 лет) на каждый показатель города.

## 1. Верхняя панель (всегда видна)
| Показатель | id | Формула | Обновление |
|---|---|---|---|
| Деньги | `money` | баланс, ₽ | тик |
| Сальдо в месяц | `netMonthly` | прогноз: доходы − расходы за последние 30 дн | день |
| Население | `population` | Σ residents | день |
| Δ населения | `popDeltaMonth` | pop − pop(30 дн назад), % | день |
| Спрос R/C/I | `demandR/C/I` | средневзвешенный по ёмкости D_X (04), шкала −1..1 → полосы | день |
| Дата, скорость | `date`, `speed` | день.месяц.год | тик |
| Счастье | `happiness` | Σ w_i·s_i (03 §3), 0–100 % | день |
| Репутация | `reputation` | 0–100 (02 §3) | месяц |

## 2. Панели
### 2.1 «Город» (сводка)
Население по классам, рабочие места R/C/I/добыча/склады, безработица `unemployment = 1 − employed/workforce`, вакантность жилья `vacancy = 1 − residents/resCapacity`, средняя стоимость земли, разложение спроса R/C/I по факторам (столбчатая диаграмма вкладов из 04 §3 — **главный инструмент причинности**).

### 2.2 «Бюджет»
Таблица доходов/расходов (03 §6) за месяц, график 12 мес, слайдеры налогов R/C/I (0–30 %) с прогнозом: `Δдохода` и `ΔD_R` = `−0.10·Δt/0.20` прямо под слайдером. Кредиты: список, платёж, остаток, доступный лимит `24·доход − долг`. Предупреждение, если `money / (−netMonthly) < cashMonthsWarn (2)`.

### 2.3 «Транспорт»
| Показатель | Формула |
|---|---|
| Доля режимов `modeShare[m]` | поездки режима / все поездки |
| Среднее время в пути `avgCommuteMin` | Σ T·t / Σ T по work-поездкам |
| Доступность работ `jobAccess45` | доля жителей, у которых ≥ 50 % рабочих мест города в 45 мин GC |
| Средний V/C `avgVC` | Σ V·len / Σ C·len по рёбрам (взвешенно по длине), пик |
| Индекс пробок `congestionIndex` | Σ T·t_actual / Σ T·t_free − 1, % (как TomTom) |
| Часы в пробках | Σ (t_actual − t_free)·V за день |
| ОТ: пассажиры/день, окупаемость | `riders`, `revenue/cost` по линиям |

### 2.4 «Экономика / товары»
По каждому из 9 товаров: производство, потребление, импорт/экспорт за день, цена и `price/basePrice`, запасы на складах в днях, дефицит `shortage = 1 − delivered/demanded`. Диаграмма Санкея цепочки (сырьё → фабрики → склады → розница).

### 2.5 «Регион»
Таблица городов: население, рост %/мес, счастье, сальдо, торговый оборот, связность (дорога/ж/д/порт). Карта торговых потоков стрелками.

### 2.6 Инспектор объекта
- Дорога: тип, V, C, V/C, скорость факт/своб., доля грузовиков, стоимость содержания.
- Здание: тип, уровень, жители/рабочие места, класс, счастье с разложением, причина «не растёт» (наибольший отрицательный фактор).
- Линия ОТ: пассажиропоток по перегонам (полоска загрузки), интервал, число ТС, окупаемость, тариф.
- Склад/фабрика: запасы, входы/выходы, простои, заказы.

## 4. Оповещения
Проверка раз в день, не чаще 1 раза в 3 дня на один тип+объект.
| Оповещение | Условие | Важность |
|---|---|---|
| Пробка | ребро V/C > `congestionVC` 0,9 в пик 2 дня | средняя |
| Дефицит товара | shortage > `goodsShortage` 0,15 | средняя |
| Безработица | unemployment > `unemployment` 0,10 | высокая |
| ОТ переполнен | load > `transitOverload` 1,1 | средняя |
| Мало денег | запас < 2 мес расходов | высокая |
| Долг / внешний управляющий | 01 §6 | критическая |
| Веха / разблокировка / поручение | 02 | инфо |
| Расширение (участок доступен, тендер, квота, предложение соседа) | 08 §8 | инфо/средняя |
| Маршрут: новая заявка, ответ, отзыв согласия, спор, истечение | 09 §6 | средняя/высокая |

## 5. Формулы ключевых показателей (сводка)
```
unemployment = 1 − employed / workforce
vacancy      = 1 − residents / Σ(RES L·40)
happiness    = Σ w_i s_i          (03 §3)
avgVC        = Σ_e V_e·len_e / Σ_e C_e·len_e
congestionIndex = Σ_od T·t / Σ_od T·t0 − 1
jobAccess45  = Σ_i pop_i·[jobsWithin45_i ≥ 0.5·jobs_city] / pop_city
goodsSatisfaction = Σ delivered / Σ demanded
budgetHealth = clamp(0.5 + netMonthly / (2·income), 0, 1)
growthRate   = rate_R (04 §5) · 30, %/мес
```

## 6. Расширение, маршруты, вовлечённость
Лента событий, всплывающие числа, газета, советники и анти-спам — 10 §4 и §8 (P1, P2, P10, P13).

Метрики и панели территорий и соседей — 08 §8; панель заявок на маршруты, статусы, окупаемость, загрузка и доходы по регионам — 09 §6.

Оверлей пробок по уровням и цветам — 12 §4; профиль загрузки линий, посадки/высадки, прибыльность — 15 §6; подземный вид — 14 §4.
