# 16. Зонирование и кварталы от дорог

Ответ на A9, F2, F3 из `USER_FEEDBACK_2.md` и F1 (темы застройки). Зоны больше не красятся по сетке тайлов: их нарезают **от дорог**, как в Cities: Skylines. Связано с 13 (сеть, доступ), 02 (рост), 11 (классы дорог), 18 (снос). Константы — `BALANCE.zoning`.

## 1. Понятия
- **Фронт (Frontage)** — полоса вдоль одной стороны ребра дороги, на которой можно зонировать.
- **Лот (Lot)** — участок под одно здание: ширина по фронту × глубина от красной линии.
- **Квартал (Block)** — замкнутая грань планарного графа дорог (ячейка между улицами).
- **Двор (Courtyard)** — внутренняя часть квартала, которую лоты не закрывают.

## 2. Структуры
```ts
type Side = -1 | 1;                         // слева/справа по направлению ребра
interface Frontage { edgeId: number; side: Side; t0: number; t1: number; roadClass: 'lane'|'street'|'avenue'; depth: number; }
interface Lot {
  id: number; blockId: number; edgeId: number; side: Side;
  t: number;                  // позиция центра по ребру 0..1
  width: number; depth: number;   // м
  corner: boolean;            // угловой лот (фронт на 2 дороги)
  poly: [number, number][];   // 4–6 вершин, мировые XZ
  zone: Zone | null; theme: ThemeId | null; buildingId: number | null;
  access: boolean;            // есть связь с главной компонентой (13 §9)
}
interface Block { id: number; ring: number[]; /* id рёбер по часовой */ area: number; lots: number[]; courtyard: Courtyard | null; theme: ThemeId | null; }
interface Courtyard { blockId: number; poly: [number, number][]; area: number; kind: 'green'|'parking'|'driveway'|'playground'|'mixed'; paths: [number, number][][]; parkingSpots: number; }
```

## 3. Длина фронта и глубина лота по типу дороги
| Класс | Глубина лота, м (`depth`) | Ширина лота, м (`lotWidth` min–max) | Этажность (доля maxL) | Фронт с двух сторон | Отступ от красной линии, м |
|---|---|---|---|---|---|
| lane (Переулок) | 24 (1,5 тайла) | 12–20 | 0,4 | да | 3 |
| street (Улица) | 32 (2 тайла) | 16–28 | 0,7 | да | 4 |
| avenue (Проспект) | 48 (3 тайла) | 24–40 | 1,0 | да | 6 |
| highway / ramp | — (не зонируется) | — | — | нет | санитарный разрыв 30 м |

Длина полосы застройки = длина ребра минус **угловые зазоры** у узлов: `cornerGap = w_cross/2 + depthCross·0.0 + 2` — фронт начинается от красной линии пересекающей дороги (см. §4), то есть почти от угла.

## 4. Нарезка (алгоритм)
1. **Грани графа**: обход планарного графа (рёбра — полилинии кривых 11 §6, сэмплированные через 4 м) → список блоков. Внешняя грань и грани с площадью < `minBlockArea` = 1 200 м² не зонируются.
2. **Фронты**: для каждого ребра класса lane/street/avenue и каждой стороны — фронт `[t0, t1]`, обрезанный на `cornerGap` у узлов. Глубина — из таблицы §3, но не больше `0,5 · ширина блока − courtyardMin/2` (если квартал узкий, лоты с двух сторон не перекрываются; разница уходит во двор).
3. **Углы и стыки**: в каждом узле соседние фронты одного блока стыкуются **угловым лотом**: его полигон — пересечение двух полос глубиной depth₁ и depth₂, ширина = max(depth₁, depth₂). Угловой лот получает класс старшей дороги. На изгибе (узел степени 2, угол > 10°) полоса строится по смещённой кривой (offset), выпуклая сторона — расширяющиеся трапеции, вогнутая — сужающиеся; лот у́же `lotWidthMin·0,7` сливается с соседом.
4. **Деление на лоты**: фронт длиной `L` делится на `n = floor(L / lotWidthTarget)` лотов, `lotWidthTarget` = (min+max)/2 класса, остаток распределяется поровну; случайный разброс ±15 % (seed).
5. **Конфликты**: пересечение полигонов лотов двух фронтов → остаётся лот старшего класса, у младшего обрезается глубина; лот с глубиной < `minLotDepth` = 12 м удаляется.
6. **Двор**: площадь блока минус лоты → `Courtyard` (§5).
7. **Привязка к тайлам** (совместимость с текущей сеткой `TILE` = 16 м и `Z`): тайл получает зону лота, если ≥ 50 % его площади внутри лота. Симуляция (02) продолжает работать по тайлам, рендер ставит здание по полигону лота, ориентированное фасадом на дорогу.

Пример: квартал s08 140 × 140 м по осям, улицы 9 м. Внутренний размер 131 м. Глубина 32 м с 4 сторон → двор 131 − 64 = 67 м × 67 м = 4 489 м² (26 % квартала). Фронт стороны 131 − 2·32 = 67 м между угловыми лотами → 3 лота по 22 м + 2 угловых 32×32 м. Итого 4·3 + 4 = 16 лотов на квартал.

## 5. Дворы (F2)
| Площадь двора, м² | Тип по умолчанию | Содержимое |
|---|---|---|
| < 400 | `green` | газон, 2–5 деревьев |
| 400–2 500 | `driveway` | въезд с улицы (переулок 4 м, без трафика в 05), 1 парковочное место на 2 квартиры R, деревья |
| 2 500–8 000 | `mixed` | дорожки, детская площадка, парковка по периметру, сквер в центре |
| > 8 000 | `parking` (C/I) или `green`-парк (R) | для R центральная часть становится мини-парком: +`courtyardParkEffect` к счастью (02) радиусом 60 м |

- Въезд во двор (`driveway`) — только с улицы или переулка, не с проспекта, если есть альтернатива; не ближе 20 м к перекрёстку.
- Парковка: `spotsPer100m2` = 3,5 места на 100 м² покрытия; машины во дворах — декоративные, их число = 30 % парковки днём, 80 % ночью (по суточной кривой 05).
- Минимальный двор для R: `courtyardMin` = 12 м; если меньше, лоты укорачиваются.

## 6. Доступ
- Лот доступен, если его ребро в главной компоненте (13 §9) и класс ≠ highway. Угловой лот — если доступно хотя бы одно из двух рёбер.
- Пешеходный доступ (`pedestrian`, глубина 24 м) — от дорожек дворов и парков, только R и C малой этажности.
- Снос/перестройка дороги перенарезает лоты только на затронутых рёбрах; здания на лотах, ставших недоступными, деградируют (13 §12), на исчезнувших лотах — сносятся с компенсацией (18 §1).

- Зона и пешеходные дорожки без связи с дорогой не создаются и не рисуются (s06: зелёные полосы на траве). Пешеходная дорожка должна начинаться от тротуара или другой дорожки.

## 7. Темы застройки (F1)
- Тема (`ThemeId`: например «Европейская», «Советская», «Американская», «Современная») хранится на **Block**: все лоты квартала строятся в одной теме. Соседние кварталы с вероятностью `themeKeepProb` = 0,85 наследуют тему района.
- «Смешанный» — не значение по умолчанию; его можно выбрать вручную для района. Генератор назначает одну тему на город (по `CITY_KINDS`) и для пояса центра — «историческую» вариацию.

## 8. Инструменты зонирования (UI, 06)
Кисть зонирования красит **лоты** (подсветка полигонов вдоль дорог), а не тайлы. Режимы: заливка вдоль ребра, квартала целиком, свободная кисть. Глубину можно уменьшить до 50 % вручную. Подсказка показывает класс дороги, глубину и число лотов.

## 9. Производительность
Перенарезка — в воркере, инкрементально по изменённым рёбрам: ≤ 2 мс на ребро; полный город 2 000 рёбер ≈ 0,4 с при загрузке. Индекс — сетка 64 м.
