# THEMES_SPEC v4 — масштабируемые здания и темы
Код: `models/themes/{common,base,sng,classic,french,index}.ts`, палитра `palette.ts → THEMES` (+ `palette.json`).
Превью: `themes-preview.html#base|sng|classic|french|scale|night`, скриншоты `shots/v4-*.png`.

## 1. API
```ts
import { createBuilding, dimensionsLimits, fitDimensions, dimensionsFromLot, themedCacheKey, THEME_KINDS } from 'design/models';
const geo = createBuilding({ theme: 'lateSng', kind: 'resMid', width: 48, depth: 12, floors: 9, seed: 17, lit: 0.5, neutral: false });
geo.userData.dims    // { w, d, floors, bays, floorH, groundH, eave } — фактические после подгонки
geo.userData.details // { downpipe: 4, ac: 34, entrance: 4, elevatorOverrun: 4, … }
```
- Старый вызов `createBuilding('house', {…})` работает как раньше (перегрузка). Также `createModel({ type: 'themed', opts })`, `KINDS.themes`.
- `theme`: `base | lateSng | russianClassic | french`. `kind`: `resSmall | resMid | resHigh | commercial | office`. Если типа в теме нет (resHigh в исторических темах), `fallbackKind()` подставляет resMid.
- Вместо `floors` можно передать `height` (м до карниза). `detail: 0` — без мелочи (дальний LOD).
- `dimensionsLimits(theme, kind)` → `{ w:[min,max], d:[min,max], floors:[min,max], module, dModule, floorH, groundH, setback }`.
- Автоподгонка `fitDimensions`: ширина = целое число модулей (окна НЕ растягиваются, вниз — чтобы влезть в участок), глубина кратна `dModule`, этажи — clamp.
- Ночь: стекло окон пишет атрибут `glow` (как в v2), светятся `lit`-доля окон, витрины, вывески, фонари подъездов. `neutral: true` — стены 0.93 серые под instanceColor, акценты (крыши, рамы, маркизы) остаются цветными.

## 2. Как игре брать размер из участка
`dimensionsFromLot(theme, kind, lotW, lotD, density)` → `{ dims, offsetZ, fits }`:
- фасад вдоль улицы = lotW − 2·боковой отступ (у `russianClassic`/`french` отступ 0 — сплошная застройка по красной линии, соседи стыкуются торцами-брандмауэрами);
- глубина = lotD − `setback` (СНГ 6–10 м — двор/газон перед домом; классика/Париж 0);
- этажность = lerp(min, max, density) — density из спроса/стоимости земли;
- `offsetZ` — сдвиг центра здания от центра участка к улице (фасад 0 = +Z смотрит на улицу);
- `fits=false` — участок меньше минимума темы → взять другой `kind` или тему `base`.
Слияние участков: при апгрейде зоны соседние лоты объединяются → больше `width` → новые подъезды/вывески/трубы (см. §3), без смены «типа».

## 5. Как тема выбирается и сочетается
1. ~~**Настройка новой игры** — «Архитектурный стиль»: Смешанный (по умолчанию)~~ **DEPRECATED v5 (F1): режим «Смешанный» убран — см. §6.** Было: Смешанный (по умолчанию) / Пастила / Позднее СНГ / Российская классика / Париж. Не «смешанный» = тема для всех новых зданий; base остаётся для промзоны/сервисных.
2. **Смешанный: по району и эпохе.** У каждого квартала есть `epoch` = игровой год первой застройки:
   - центр города (≤ 1.2 км от ядра, первые 15 лет игры) → `russianClassic` (или `french`, если регион «Западный» / seed);
   - кольцо новостроек (застройка в годы 10–40 или зона высокой плотности на окраине) → `lateSng`;
   - поздние районы / бизнес‑центр → `base` (стекло, офисы).
   Тема квартала фиксируется при первой постройке и наследуется при апгрейде (дом растёт в своей теме).
3. **Смешение в одном городе.** Квартал — одна тема; на стыке районов допускается 20 % «вкраплений» соседней темы (по seed лота). Высотные resHigh в исторических темах запрещены — подменяются resMid (fallbackKind), а в центре действует ограничение высоты.
4. **Жители и цены.** Стоимость земли ↑ → density ↑ → больше этажей и ширины (слияние лотов) → больше деталей. Классика/Париж в центре дают +10–20 % к стоимости земли соседям (престиж), СНГ — дешевле (+вместимость). Богатые жители → больше остеклённых лоджий и кондиционеров (коэф. AC ×1.5), бедные — меньше.
5. **Инстансинг.** Детали вклеены в геометрию здания (один draw call). Кэш по `themedCacheKey` (тема/тип/модули×глубина×этажи/seed%4/neutral/detail): одинаковый ключ → одна геометрия → один InstancedMesh; цвет стен — instanceColor при `neutral`. Квантование по модулю держит число уникальных геометрий ~ сотни, а не тысячи. Дальний LOD: `detail: 0` или v2‑коробка той же высоты.


## 6. v5 · Тема — свойство зоны (F1), «Смешанный» — DEPRECATED
- Режим «Смешанный» (и смешение по эпохе, §5 п.2) **устарел**: не показывать в настройках, не использовать по умолчанию.
- Тема выбирается кистью зонирования: панель над инструментом «Зона» — Позднее СНГ (по умолчанию) / Российская классика / Париж / Пастила; Shift+колесо — смена темы. Хранить `zoneTheme[k]` на тайле; дом берёт тему своего участка; в одном квартале смешения нет — при перекраске кистью квартал перекрашивается целиком (по blockId), дома перестраиваются при следующей застройке.
- Цвет-образец темы на оверлее зон: ZONE_THEME_UI.swatch (design/yards.ts), обводка квартала 2 px.
- Промзона и сервисные здания — всегда base.
