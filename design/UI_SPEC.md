# CitySim — спецификация интерфейса

Прототипы: `ui-prototype.html` (HUD + экономика + транспорт + уведомления + тулбар + легенда), `menu-prototype.html` (новая игра). Скриншоты: `shots/ui-hud.png`, `shots/ui-new-game.png`. CSS-кит: `ui.css` (классы `.cs-*`), токены: `palette.ts → UI`, `palette.json`.

## 0. Принципы
- **Стекло над миром**: тёмные полупрозрачные панели (`--bg1`, blur 14px), мир всегда виден. Панели не перекрывают центр экрана.
- **Цифры моноширинные** (`tabular-nums`), деньги — золото `--money`, рост `--pos`, падение `--neg`.
- **Цвет = категория**: R `--res` зелёный, C `--com` синий, I `--ind` оранжевый, ОТ `--transit` фиолетовый; линии — бейджи цвета вида транспорта.
- Всё доступно с клавиатуры; у каждой кнопки тултип с хоткеем; `prefers-reduced-motion` отключает анимации.
- Масштаб UI: 80–150% (настройка), базовая сетка 4 px.

## 2. HUD (верхняя полоса)
```
┌─────────────┐ ┌──────────────────────────────────────────────┐            ┌──────────────────────────┐
│ Новоречинск │ │ БЮДЖЕТ ₽12 480 300 │ +184 200▲ │ НАСЕЛ. 118 452 │            │ 14 мая 2031 ❚❚ ▶ ▶▶ ▶▶▶ ⚙ │
│ Город·seed  │ │ ДОВОЛЬСТВО 78% │ СПРОС ▮▮▯ (R C I)           │            └──────────────────────────┘
└─────────────┘ └──────────────────────────────────────────────┘
```
- Высота 44 px, отступ 12 px от краёв. Label 11px uppercase mute, value 18px bold.
- Состояния: бюджет < 0 → значение `--neg` + пульс 1.2 с; доход/мес со стрелкой ▲▼; довольство цвет по шкале happiness.
- Клик по бюджету → панель экономики; по населению → аналитика; по RCI → тепловая карта спроса.
- Скорость: `Пробел` пауза, `1/2/3` скорости. Анимация смены числа: count-up 320 мс.

## 4. Панель транспорта (справа, 320 px; `L`)
```
┌ ⧉ Транспорт ──── [+ Новая линия] ┐
│ Линия               ТС  Пасс/мес Загр │
│ [12] Вокзал—Заречье  8   41 200  118% │ ← красный если >100%
│ [Т1] Кольцевая       5   63 900   74% │
│ ── Выбрана линия: схема-полоса с остановками ●──●──●, интервал, цена билета, ТС (+/−) │

```
Режим редактора линии: клик по остановкам на карте, линия рисуется цветом бейджа шириной 6 px с белой обводкой; `Esc` — отмена, `Enter` — готово. Бейдж линии: 20 px высота, радиус 5, цвета `--bus/--tram/--rail`.

## 5. Инструменты строительства (нижний тулбар)
```
[Дорога R][Зоны Z][Здания B] | [Автобус T][Трамвай Y][Ж/Д U] | [Слои H][Графики G][Снос X]
```
- Кнопка 48×48, иконка 24, хоткей в углу 9px. Активная — заливка accent + тень. Подпанель (вылет вверх 8 px): варианты (дорога: грунтовая/улица/проспект/трасса; зоны R/C/I низкой/высокой плотности; кисть/прямоугольник).
- Призрак строительства: синий полупрозрачный `#4fb3ff` 40%; невалидно — `#ff6b5e` 40%; стоимость у курсора в тултипе (`.cs-tooltip`), длина в метрах.
- Снос: курсор красный, подтверждение при > ₽100 000.

## 6. Тепловые карты (`H`, циклически `Shift+H`)
Оверлей окрашивает землю/здания (здания десатурируются на 70%). Легенда справа внизу 220 px: название, градиент 10 px, подписи min/mid/max, чипы переключения.

| Загрязнение | `#f2f2e8 #d9d39a #b8a05a #8a6a4a #4a3a32` |

Переход оверлея: crossfade 320 мс.

## 7. Графики и аналитика (`G`, модальное окно 960×600)
Вкладки: Население · Бюджет · Транспорт · Спрос RCI · Трафик. Линейные графики SVG/Canvas: линия 2 px, area 18%, сетка 6% белого, ось подписи 11 px mute, hover — вертикальная линия и тултип со значениями всех серий. Диапазоны: 1 год / 5 лет / всё. Цвета серий: pos/neg/res/com/ind/transit.

## 8. Уведомления (тосты, справа сверху, стек ≤ 4)
`.cs-toast` 320 px, полоса слева 3 px по типу (info/warn/bad/good), иконка, заголовок 13/600, текст 12 dim. Вход справа spring 320 мс, авто-скрытие 6 с (bad — не скрывается), клик — камера летит к объекту. Лента событий — колокольчик в HUD (`N`).

## 10. Настройки (`Esc` → Настройки, модальное 720 px, вкладки слева)
- **Графика**: пресет Низко/Средне/Высоко/Ультра; тени (выкл/1024/2048/4096); SSAO; Bloom; сглаживание; Режим макета (tilt-shift); дальность прорисовки; масштаб рендера 50–100%; FPS-счётчик.
- **Игра**: автосохранение (5/10/30 мин), скорость прокрутки, инверсия камеры, время суток (авто/фикс), сезоны вкл/выкл.
- **Интерфейс**: масштаб UI, цветовая схема для дальтоников (замена трафика на viridis), язык.
- **Звук**: общий/музыка/эффекты. **Управление**: таблица хоткеев с переназначением.
Контролы: `.cs-seg`, `.cs-toggle`, `.cs-select`, слайдер. Изменения графики применяются сразу (превью), «Сбросить» внизу.

# v2 — премиальный интерфейс (актуально; классы v1 `.cs-panel/.cs-toolbar/.cs-stat` заменены)
- **Шрифты:** Inter (текст, цифры с `font-variant-numeric: tabular-nums` → `.cs-num`), Manrope (заголовки, `--display`). Файлы: design/fonts/ (OFL).
- **Иконки:** единый inline-SVG набор `icons.svg.html` (24×24, stroke 1.75, round caps). Использование: `<svg class="cs-ico"><use href="#i-road"/></svg>`. 23 иконки: road, zone, build, bus, tram, rail, layers, chart, bulldoze, pop, coin, smile, cog, bell, pause, play, ff, dice, arrow, alert, sparkle, x, sun.
- **Стекло:** `.cs-glass` — blur 22px + saturate, полупрозрачный индиго, внутренняя 1px-обводка, мягкая тень. Радиусы: 6/8/12/18/24.
- **Компоненты:** `.cs-dock/.cs-tool` (нижний док, активный — teal-градиент со свечением), `.cs-btn(--primary|--icon|--lg)`, `.cs-seg`, `.cs-slider`, `.cs-toggle`, `.cs-input`, `.cs-chip(--on)`, `.cs-list/.cs-row`, `.cs-badge` (номер линии в цвете вида ОТ), `.cs-toast` (иконка в цветной плашке + время), `.cs-tooltip` (с `.cs-kbd`), `.cs-legend__ramp/__ticks`, `.cs-meter`, `.cs-delta--up/down`, `.cs-chart`.
- **Микро-взаимодействия:** hover — подъём на 1px и осветление, press — scale .96, появление панелей `.cs-enter` (fade + translateY 8px, 240 мс, ступенчато через animation-delay 40 мс), тосты въезжают справа. Всё в `prefers-reduced-motion` отключается.
- **Графики:** SVG, сглаженные кривые (cubic), area-градиент под линией дохода, линия-курсор и тултип при hover, сетка 6% белого.
- **Раскладка HUD (1600×900):** верх — бренд, статы (бюджет, население, довольство, RCI), часы и скорость; слева — контекстная панель 360px; справа — тосты и панель транспорта 340px; низ-центр — док; низ-право — легенда слоя.
- Прототипы: ui-prototype.html (HUD), menu-prototype.html (новая игра). Скриншоты: shots/v2-ui-hud.png, shots/v2-ui-new-game.png.
