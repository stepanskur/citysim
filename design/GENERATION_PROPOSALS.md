## Пробелы
1. Нет поля **эпох**: стиль (`style` 0–3) выбирается шумом, а не историей роста.
2. Только **одно кольцо** и только у формы `radial`.
3. Реки строятся жадным спуском: без меандров, поймы и озёр.
4. **Нет ж/д**, поэтому промзона привязана к углу `indDir`, а не к инфраструктуре.
5. Застройка **потайловая** (1 тайл = 1 здание): нет периметральных кварталов, дворов, угловых акцентов.
6. Нет **набережных и площадей**, мосты не ограничены.
7. Нет выходных полей состояния (`wealth`, `age`, `pollution`) для визуала.

## П1. Поле эпох
```ts
// после построения сети, до зонирования (перед стр. 294)
const epoch = new Float32Array(N*N);
for each tile k in city c:
  d   = hypot(x-c.x, (z-c.z)*1.1) / c.r
  ray = min(distToRadial(x,z), distToRiver(x,z), distToRail(x,z)) / c.r   // рост вдоль «лучей»
  epoch[k] = clamp(d*1.15 - 0.25*exp(-ray*8) + (nz.fbm(x*.002,z*.002,3)-.5)*0.3, 0, 1)
// вместо шумовых panel/slum/core:
st = epoch<.2 ? 3 /*историч.*/ : epoch<.45 ? 0 /*доходн.*/ : epoch<.75 ? 2 /*панели*/ : (slum>slumT ? 1 : 0 /*ИЖС*/)
```
Параметры: `EPOCH_CORE=0.2`, `EPOCH_TENEMENT=0.45`, `EPOCH_PANEL=0.75`, амплитуда шума 0.3, вес лучей 0.25.
Этажность: `bld = base[st] * fall * (1 + 0.8*accessOT)`, где `base = {hist:4, tenement:6, panel:12, new:20|2}`. Для `epoch>0.75` — **бимодально**: у развязок и проспектов (`ave`) башни 17–25, в остальных местах 1–2.

## П2. Кольца и ориентация сетки
```ts
const nRings = {small:1, mid:2, big:3, huge:4}[sizeClass(c.r)];
for (i=0;i<nRings;i++){
  R = c.r * [0.22,0.45,0.72,1.0][i];
  pts = []; for a in 0..2π step 0.08:
     r = R*(1+(nz.fbm(cos a*2+i, sin a*2)-.5)*0.25);   // неровное кольцо
     p = c + (cos a, sin a*aniso)*r
     if (water(p) && !bridgeAllowed(p)) { flush segment; continue; } // разрыв рекой
     pts.push(p)
  addRoadPolyline(pts, i===0 ? 'street' : i===nRings-1 ? 'highway' : 'avenue')
}
// сектора: угол сетки = угол ближайшего радиуса, а не случайный
gridAngle(sector) = atan2 of radial at mid-angle; blockSize = lerp(48, 160, epochAt(sectorCenter))
```
Кольца строятся для всех форм кроме `linear`/`grid`. Для `hilly` — по изолиниям: `R` берётся там, где `hAt` ≈ const.

## П5. Кварталы и периметральная застройка (самое заметное)
1. Из графа RoadNet находим грани (планарные циклы) — это полигоны кварталов.
2. Полигон сжимаем на `ширина_улицы/2 + тротуар`.
3. Нарезаем участки (lots) перпендикулярно рёбрам. Глубина — по эпохе: исторические 12–18 м, доходные 14–20 м по периметру с двором, панели — 1–3 «пластины» 12×60 м с ориентацией на юг, ИЖС — 20×30 м.
4. Угловые участки получают флаг `corner` → акцентное здание (на 1–2 этажа выше, коммерческий 1-й этаж).
5. Центр квартала: двор (дерево, площадка, гаражи 10%), у панелей — школа или детсад, если в радиусе 800 м их нет.
Совместимость: тайловую сетку оставить для симуляции, а lots хранить отдельным массивом `lots: {poly, kind, floors, seed, rot}` для рендера. Модели уже берут `lotW/lotD/seed` (design/models).

## П6. Площадь, бульвары, клинья
- Площадь 3×3 тайла в центре (ратуша `civic` + собор), к ней сходятся радиусы.
- Внутреннее кольцо — бульвар: средняя полоса из деревьев (TREES.alley).
- Зелёные клинья: `|sin((ang-φ)*nRad/2)| < 0.1 && d > 0.4` → парк. Это не шумовые пятна, а полосы между радиусами (см. прототип).

## П7. Поля состояния (визуал от состояния)
```ts
wealth[k]    = clamp(landValue[k] * (1 - pollution[k]*.6), 0, 1)   // вариант модели, солнечные панели, мансарды
age[k]       = epoch[k]                                            // палитра: старое теплее и темнее
pollution[k] = Σ ind within 6 tiles * windFalloff                  // tint травы, дымка
vacancy[k]   = 1 - occupancy                                       // порог glow окон: lit = 1 - vacancy
```
В рендере: `createModel({type:'building',kind,opts:{seed,lit:1-vacancy}})` и `instanceColor` = mix(базовый, серый, decline).

## П8. Несовершенство
- 5–8% тайлов внутри города — пустыри (`dn < -0.25`, уже есть; добавить и в центре 2%).
- Разнобой этажности ±1 по `bh(i,j)` уже есть. Добавить в 3% случаев «старый дом среди новых»: `epoch -= 0.3` для одиночного тайла.
- Гаражные кооперативы (ряд 3×1 коробок) у ж/д и в панельных районах — 1 на 40 тайлов.
