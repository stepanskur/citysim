## Этап V3–V4 — реализм города, характер городов, дизайн, интеграция маршрутов (23:00–23:15)
**Исправлено:** `cam is not defined` в Renderer (обрезанная строка после правки теней) — устранено.
**Дороги:** ленты дорог ранее отсекались back-face culling (были видны только тёмные «пятна» из цвета земли) → `DoubleSide`; ширина отрисовки 0.8× от расчётной; светло-серый асфальт палитры; разметка пунктир 3/6 м на улицах и проспектах; перекрёстки цветом примыкающей дороги; под дорогами — цвет тротуара, а не тёмные мазки; земля в плоских цветах без шума; тени только при дистанции < 1.8 км, frustum 150–1200 м (чёткие).
**Иерархия улиц:** магистрали — единицы: радиальный 5–6 лучей + 1 кольцо, линейный/речной 2 (вдоль оси), сеточный 2, прочие 3–4; плановые сетки строятся улицами/переулками (без проспекта каждые 6 кварталов).
**Застройка (Renderer.buildBuildings):** участок = тайл 16 м; здание фасадом (+Z модели) к ближайшей улице, ось вдоль неё, отступ от красной линии (дома 4 м, истор. 0.5 м, ср. этажн. 3 м); габарит вписан в участок и проверяется по 8 точкам периметра против всех дорог (сжатие ×0.72 до 2 раз, иначе участок пуст) → дома не режутся дорогами; ширина лота варьирует 72–100 %, 15 % участков ИЖС пустые (дворы); палитра стен единая на «район» 5×5 участков; этажность = 0.75·среднее по 5×5 + 0.25·своя → плавный градиент; модели из design/models (house/resMid/resTower/commercialSmall/office/industrial/warehouse/station), деревья createTree только в парках/вдоль улиц и лес вне городов, фонари createProp('streetLight'); материал `vertexColors: true`; транспорт — модели car/truck/bus/tram/локомотив+вагоны.
**Зонирование:** порог коммерции/заполнения по хэшу квартала 4×4 (а не по тайлу), без случайных «свечек»; зелёный буфер (парк) между сектором промзоны и жильём; поля-полосы вокруг города (d > 1.05).
**Характер городов (по seed+рельеф):** сеточный, радиально-кольцевой, линейный, полицентричный, холмистый, портовый, речной, курортный — влияет на контур (анизотропия вдоль оси/берега), размер ядра, число секторов и их углы, магистрали, кольца, доп. ядра, доли парков/панелек/трущоб/промки. ## Этап V5 — публичная ссылка и высоты (23:20–23:35)
**Публичная ссылка: не получена — сеть box не пропускает туннели.** Диагностика:
- DNS любого внешнего хоста → 198.18.0.1 (прозрачный egress-прокси `runner-egress-proxy`); TCP-connect открывается на любой порт, но дальше проходит только HTTP(S).
- cloudflared: QUIC — timeout, `--protocol http2` — «TLS handshake with edge error: EOF» (URL выдаётся, но 530).
- ssh localhost.run (22) и pinggy (443): «Connection closed by 198.18.0.1».
- bore.pub:7835: «timed out waiting for initial message».
- localtunnel: URL выдаётся, но обратный TCP на loca.lt не проходит → 502/503. tunnelmole (порт 8083): ошибка соединения.
- Статические хостинги без логина: 0x0.st — загрузки отключены; catbox / litterbox / tmpfiles отклоняют загрузку («No file!» / «Invalid file name»). surge / netlify / vercel / Cloudflare Pages требуют аккаунт.
- Варианты: (1) подключить GitHub (connect_github) → GitHub Pages из `dist/` (base './' уже настроен); (2) пользователь сам выполняет `npx surge dist` или Netlify Drop с архивом `dist/`; (3) запустить проект локально: `npm i && npm run build && npx vite preview`.

**Высоты:** градиент этажности круче (`(1−d)^2.6`), для размеров ≤ «Город» ×0.6 → меньше башен 8+ в центре малых городов.
